# My Magical Tiny World

Static site for My Magical Tiny World, the home of the magical tiny elves: handmade elves who review the best 1:12 miniatures.

Plain HTML and CSS, hosted on GitHub Pages. No build step, no backend, no payments.

## Pages

| Journal | `journal.html` | done |
| About | `about.html` | done |

## Layout

- `css/tiny.css`: the one stylesheet (paper, ink, oak and moss)
- `js/tiny.js`: lets visitors nudge the taped photos around with a mouse
- `assets/img/`: web-sized copies of Gisi's own art and photos (originals live outside the repo)

## Preview locally

Open `about.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.
